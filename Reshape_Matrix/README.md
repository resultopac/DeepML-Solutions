# Reshape Matrix

**Difficulty**: Easy | **Category**: Linear Algebra

## Description

Write a Python function that reshapes a given matrix into a specified shape. if it cant be reshaped return back an empty list []

### Example:

- **Input:** a = [[1,2,3,4],[5,6,7,8]], new_shape = (4, 2)

- **Output:** [[1, 2], [3, 4], [5, 6], [7, 8]]

- **Reasoning:** The given matrix is reshaped from 2x4 to 4x2.
